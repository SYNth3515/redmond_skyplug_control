# SkyPlug Control (Redmond RSP-103S) для Windows
1. Установите Python с python.org (галочка "Add to PATH", tcl/tk включён по умолчанию).
2. Запустите `run_app.bat` - он поставит библиотеку bleak и откроет приложение.
3. Если розетка уже спарена скриптами, положите рядом ваш `rsp103s_token.hex`. Иначе: «Найти розетку» -> «Спарить» (зажать кнопку на розетке) -> «Обновить».
4. Отдельный .exe без Python: `build_exe.bat` -> `dist\SkyPlugControl.exe` (иконка `skyplug.ico` уже вшивается; пересоздать её можно через `make_icon.py`, нужен Pillow).
Закройте оригинальное приложение Redmond и Home Assistant: розетка принимает одно BLE-подключение.

## Несколько розеток
Сверху выпадающий список розеток и кнопка «＋ Розетка» (поиск поблизости, своё название, адрес и токен у каждой).
Календарь, события и команды относятся к выбранной розетке. Список хранится в `rsp103s_app.json` рядом с программой.
Если вы пользовались прошлой версией с одной розеткой, она станет «Розетка 1» (адрес из `rsp103s_app.json`, токен из `rsp103s_token.hex`).
