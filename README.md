Самодельное приложение для Android и Windows для настройки и управления умными розетками REDMOND SkyPlug (протесчено на rsp 103s).
Сделал потому что в новом приложении REDMOND розетки убраны, а в старой версии - не работает их настройка.

Скачать:
Android - https://github.com/SYNth3515/redmond_skyplug_control/releases/download/24.10.2026/SkyPlugControl_Android.apk
Windows - https://github.com/SYNth3515/redmond_skyplug_control/releases/download/24.10.2026/SkyPlugControl_Windows.exe

Обращаю внимание, что при установке необходимо на этапе проверки приложения Google Безопасностью раскрыть список "Подробнее" и выбрать неприметную строку "Установить без проверки" т.к. приложение без подписи.
Порядок работы приложения на Android:
1) Зажимаем на розетке кнопку отключения 5 сек - включится режим пары (10 сек сбросит пару, на всякий случай)
2) Заходим в настройки блютуз, находим нашу розетку и подключаем (шаг может быть пропущен если ваше устройство найдет его в приложении и так).
3) Заходим в приложение, нажимаем найти - найдет и подставит блютуз адрес розетки
4) Нажимаем спарить, розетка подключится к приложению.

На Windows порядок идентичный, только розетку добавлять в блютуз устройства не нужно.
