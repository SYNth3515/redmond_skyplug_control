# Redmond RSP-103S (Android)
Приложение управляет розеткой по BLE напрямую: вкл/выкл, блокировка кнопки, часы, календарь событий (расписание внутри розетки).

## Как получить APK
**Вариант A (без Android Studio):** создайте репозиторий на GitHub, загрузите в него содержимое этой папки,
откройте вкладку Actions → «Build APK» → Run workflow. Через несколько минут скачайте артефакт `rsp103s-debug-apk` (внутри app-debug.apk).
**Вариант B:** откройте папку в Android Studio (Koala или новее), Build → Build APK(s).

Установка: разрешите установку из неизвестных источников, откройте app-debug.apk.

## Несколько розеток
Сверху выпадающий список розеток и кнопка «＋ Розетка» (поиск поблизости, своё название, адрес и токен у каждой).
Календарь, события и команды относятся к выбранной розетке. Настройки выбранной розетки (название, адрес, токен, удаление) - внизу.
